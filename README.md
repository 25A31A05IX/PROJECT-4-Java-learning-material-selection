📚 Inclusive Learning-Material Selection Under Budget

🎓 ADS & AA Java Project

📌 1. Project Overview

This project focuses on selecting educational materials within a limited budget while maximizing accessibility benefits. It uses the 0/1 Knapsack Dynamic Programming Algorithm to identify the best combination of learning materials.

🎯 2. Problem Statement

To select a subset of educational materials that provides maximum accessibility benefit without exceeding the available budget.

🎯 3. Objectives

- 📖 Select educational materials within a given budget.
- 💡 Maximize total accessibility benefit.
- ⚙️ Apply the 0/1 Knapsack algorithm.
- 📊 Compare Dynamic Programming with a Greedy approach.

💻 4. Technologies Used

- ☕ Programming Language: Java
- 🧠 Algorithm: 0/1 Knapsack
- ⚙️ Technique: Dynamic Programming
- 📦 Data Structure: Arrays

✨ 5. Features

- 📝 Accept material costs and benefits.
- 💰 Set a maximum budget.
- 📈 Calculate maximum achievable benefit.
- 📚 Display selected materials.
- 🔍 Compare algorithmic approaches.

🔄 6. Algorithm

The 0/1 Knapsack algorithm uses Dynamic Programming to decide whether each material should be selected or excluded.

Each material can be selected only once.

⏱️ 7. Time and Space Complexity

- Time Complexity: O(n × W)
- Space Complexity: O(n × W)

Where:

- n = Number of materials
- W = Available budget

🚀 8. How to Run

1. Install Java JDK.

2. Download or clone this repository.

3. Open the project folder in VS Code.

4. Compile the program:
   
   "javac Main.java"

5. Run the program:
   
   "java Main"

🌍 9. Applications

- 🏫 Educational resource planning.
- 💰 Budget-based learning material selection.
- ♿ Accessibility-focused education.
- 📊 Resource optimization.

🏁 10. Conclusion

This project demonstrates how Dynamic Programming can efficiently select educational materials to maximize accessibility benefits under a limited budget.
