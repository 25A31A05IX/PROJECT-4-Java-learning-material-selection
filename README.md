# 📚 Inclusive Learning-Material Selection Under Budget


🎓 Analysis and Design of Algorithms (ADS & AA)

☕ Java Programming Project

✨ A Dynamic Programming Approach Using the 0/1 Knapsack Algorithm

📌 1. Project Overview

This project focuses on selecting educational materials within a limited budget while maximizing accessibility benefits.

It uses the 0/1 Knapsack Dynamic Programming Algorithm to identify the best combination of learning materials.

🎯 2. Problem Statement

To select a subset of educational materials that provides maximum accessibility benefit without exceeding the available budget.

The objective is to optimize the selection of educational resources while considering their costs and benefits.

🎯 3. Objectives

- 📚 Select educational materials within a given budget.
- 💡 Maximize total accessibility benefits.
- ⚙️ Implement the 0/1 Knapsack algorithm.
- 📊 Compare Dynamic Programming with a Greedy approach.
- ♿ Promote inclusive and accessible education.

🧮 6. Algorithms Used

1️⃣ 0/1 Knapsack – Dynamic Programming

- Calculates the maximum accessibility benefit.
- Each material can be selected only once.
- Ensures the total cost does not exceed the budget.
- Produces an optimal solution.

2️⃣ Greedy Algorithm

- Calculates the benefit-to-cost ratio.
- Selects affordable materials in descending ratio order.
- Provides a comparison with Dynamic Programming.
- Does not always guarantee an optimal 0/1 Knapsack solution.

⏱️ 7. Time and Space Complexity

Dynamic Programming:

- Time Complexity: O(n × W)
- Space Complexity: O(n × W)

Where:

- n = Number of educational materials.
- W = Available budget.

Greedy Approach:

- Time Complexity: O(n log n)
- Space Complexity: O(n)
